Add the Safari add-on

The add-on does two things. It puts a Send to Plate Builder button on MakerWorld model pages, which fetches the print profile you’re looking at using your MakerWorld login. And it lets Send to printer reach your Flashforge over your Wi-Fi.

1. Install the free Userscripts app from the App Store and open it once.
2. In Settings → Apps → Safari → Extensions → Userscripts, turn it on and allow it on all websites.
3. Open the add-on script in Safari, tap the puzzle-piece icon in the address bar, choose Userscripts, then Install.
4. On MakerWorld, pick a print profile and tap the yellow button. If Safari asks about pop-ups, allow them for makerworld.com.

How to print it

Open the file in Flash Studio with File → Open Project. The printer, print profile and filaments are already set, and the author’s walls, infill and supports come across. Check the colours match what’s loaded, slice, and send it to the printer.

Everything happens on this phone. Nothing is uploaded.
